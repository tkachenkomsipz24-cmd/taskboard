# Лабораторна 2. Звіт

## 5.1 Network (таблиця запитів, перезавантаження F5)

| Запит (Name) | Метод | Статус | Тип | Розмір |
|---|---|---|---|---|
| index.html | GET | 200 (або 304 при повторному завантаженні) | document | ~0.8 КБ |
| logo.png | GET | 200 (або 304) | png | розмір файлу з DevTools |
| (інші, якщо є: Live Server додає скрипт/WebSocket) | GET | 101 / 200 | script / websocket | — |

Для `index.html` у Headers: **Request URL** — `http://127.0.0.1:5500/index.html`, **Request Method** — `GET`, **Status Code** — `200 OK`, **Content-Type** — `text/html; charset=UTF-8`.

## 5.2 Помилка 404

Навмисно змінив шлях на `images/logo1.png`. У Network з'явився червоний запит `logo1.png` зі статусом **404 Not Found**. (Додай сюди скриншот.) Після виправлення шляху на `images/logo.png` картинка знову показується.

## Відповіді на запитання

1. **Яка адреса сторінки і з яких частин складається?**
   `http://127.0.0.1:5500/index.html`: протокол `http`, хост `127.0.0.1` (мій власний комп'ютер), порт `5500` (на якому слухає Live Server) і шлях `/index.html` (який файл просять).

2. **Скільки запитів зробив браузер і чому стільки?**
   Мінімум 2: один за `index.html`, другий за `logo.png`. Браузер спочатку отримує HTML, бачить у ньому тег `<img>` і окремим запитом завантажує картинку. Кожен зовнішній ресурс — окремий запит. (Live Server може додати ще запити для автооновлення.)

3. **Що відбулось, коли поставив неправильний шлях до зображення?**
   Сервер не знайшов файл і повернув статус 404. Замість картинки показався текст з атрибута `alt`, а в Network з'явився червоний запит.

4. **Чому зміни через DevTools зникли після F5?**
   DevTools змінює лише копію сторінки (DOM) в пам'яті браузера. Файл `index.html` на диску не змінюється, а після F5 браузер знову завантажує оригінал із сервера.

5. **Хто в цій схемі клієнт, а хто сервер?**
   Клієнт — браузер, який просить сторінку. Сервер — Live Server на моєму комп'ютері, який віддає файли `index.html` та `logo.png`.

## Додаткове завдання

- Створено `about.html` з посиланням на головну, а в `index.html` додано `<a href="about.html">Про проєкт</a>`.
- Запит `http://127.0.0.1:5500/qwerty` повертає **404 Not Found**, бо такого файлу немає.
- `curl -I http://127.0.0.1:5500/index.html` показує ті самі заголовки (`HTTP/1.1 200 OK`, `Content-Type: text/html`), що й вкладка Headers у DevTools.

## 5.4 Console

- `document.title` повертає `"TaskBoard"`.
- `document.body.style.background = "lightyellow"` змінює фон сторінки на світло-жовтий.
- Після F5 зміна зникає: це правка лише в пам'яті браузера.
